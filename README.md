# Kylian Mbappe 10 Project

This is a website project dedicated to the French football player Kylian Mbappe. I created this project to practice my HTML and CSS skills while documenting his full career and top achievements.

## Project Contents:
- A full text biography about Mbappe from his early days at Monaco to his superstar years.
- A career statistics table showing his appearances, goals, and assists for Monaco, PSG, and Real Madrid.
- A trophy cabinet section that lists all his major team titles like the FIFA World Cup and league championships.
- An individual awards section highlighting his personal achievements like the Golden Boot and Player of the Year awards.
- High-quality images showing important moments from his career.

## Technical Details:
I built the structure of the website using semantic HTML tags and organized the data clearly inside tables. For the design, I used CSS to create a modern dark theme with gold colors to give it a professional look. I also added hover effects on the tables to make the navigation better for users.
