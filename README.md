# ⚽ Kylian Mbappé: The Royal Journey 👑

Welcome to my project about the football phenomenon, **Kylian Mbappé**. This website explores his incredible journey from the streets of Bondy to the Santiago Bernabéu.

## 🚀 Project Overview
This is a personal web project built with **HTML5** and **CSS3**. It features detailed statistics, career milestones, and individual achievements of the French superstar.

### 📋 Features:
* **Detailed Career Statistics:** A comprehensive table of goals and assists at Monaco, PSG, and Real Madrid.
* **Trophy Cabinet:** A list of major honors including the FIFA World Cup and Ligue 1 titles.
* **Individual Awards:** Highlighting his Golden Boots, Player of the Year awards, and more.
* **Legendary Quotes:** Insights from football icons like Cristiano Ronaldo and Zinedine Zidane.
* **Responsive Design:** Styled with a professional "Real Madrid" royal theme (Gold & White).

## 🛠️ Technologies Used
* **HTML5:** For structured content.
* **CSS3:** For advanced styling, gradients, and hover effects.
* **GitHub Pages:** For hosting the live demo.

The project includes high-quality images of Mbappé during different stages of his career, styled with custom borders and shadows.
